# Jalen Brunson NBA Playoff Analytics

Analysis of Jalen Brunson's playoff performance using Python and NBA data.

## Project Goal

Explore how Jalen Brunson performed across playoff games and identify patterns
in his scoring, shot selection, and game-to-game production.

## Tools

- Python
- Google Colab
- Pandas
- Matplotlib
- NBA data / NBA API

## Analysis

This project includes:

- Game-level player analysis
- Shot and scoring visualizations
- Comparison of performance across games
- Exploratory basketball analytics

## Notebook

`NBAFinalsGame 1 and 2.ipynb`
