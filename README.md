# Jalen Brunson NBA Finals Shot Chart Analysis

Analysis of Jalen Brunson's shooting performance in Games 1 and 2 of the 2026 NBA Finals using Python and basketball shot-location data.

## Project Goal

Analyze Brunson's shot selection and shooting outcomes across the first two games of the 2026 NBA Finals and visualize where his made and missed field-goal attempts occurred on the court.

## Tools

- Python
- Google Colab
- Pandas
- Matplotlib
- NBA game and shot-location data

## Analysis

This project includes:

- Shot-location analysis for NBA Finals Games 1 and 2
- Made vs. missed field-goal visualization
- Custom NBA half-court visualization
- Comparison of shooting patterns between games
- Exploratory basketball analytics using Pandas and Matplotlib

## Games Analyzed

### Game 1
- 12-31 FG
- 2-9 3PT
- 30 points

### Game 2
- 7-25 FG
- 2-8 3PT
- 20 points
